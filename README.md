# Estudos em C

Este repositório reúne exercícios e pequenos programas desenvolvidos durante meus estudos de programação em C.

O objetivo é registrar minha evolução na linguagem e praticar conceitos fundamentais de lógica de programação, estruturas condicionais, laços de repetição, funções, vetores, strings e manipulação de caracteres.

## Exercícios

- Caesar
- Crédito
- Crescimento Populacional
- Legibilidade
- Mario
- Scrabble
- Substituição
- Troco

## Conceitos praticados

Durante os exercícios foram utilizados conceitos como:

- Variáveis e tipos de dados
- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Vetores e strings
- Manipulação de caracteres
- Validação de entrada
- Argumentos de linha de comando
- Operações matemáticas

## Objetivo

Este repositório faz parte dos meus estudos iniciais em programação e será atualizado conforme eu avançar no aprendizado da linguagem C e desenvolver novos exercícios e projetos.
